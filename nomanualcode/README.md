# nomanualcode (backend)

A Spring Boot REST API for creating, reading, updating and deleting `Person` records. Data is stored in an in-memory H2 database.

## Tech stack

- Java 26 (Gradle toolchain)
- Spring Boot 4.1.1: Web MVC, Data JPA, H2 console
- H2 in-memory database
- JUnit 5 + Spring Boot Testcontainers support

## Running

```sh
./gradlew bootRun          # Windows: gradlew.bat bootRun
```

The server starts on <http://localhost:8080>.

Other useful tasks:

```sh
./gradlew test             # run tests
./gradlew build            # compile, test and package build/libs/*.jar
java -jar build/libs/nomanualcode-0.0.1-SNAPSHOT.jar
```

## API

Base path: `/api/persons`

| Method | Path | Description | Responses |
|---|---|---|---|
| `GET` | `/api/persons` | List all persons | `200` |
| `GET` | `/api/persons?lastName=smith` | Filter by last name (case-insensitive) | `200` |
| `GET` | `/api/persons/{id}` | Get one person | `200`, `404` |
| `POST` | `/api/persons` | Create a person | `201` with `Location` header |
| `PUT` | `/api/persons/{id}` | Replace a person's fields | `200`, `404` |
| `DELETE` | `/api/persons/{id}` | Delete a person | `204`, `404` |

### Person JSON

```json
{
  "id": 1,
  "firstName": "John",
  "lastName": "Doe",
  "email": "john.doe@example.com",
  "dateOfBirth": "1990-05-14"
}
```

`id` is generated by the database and ignored on create and update. `firstName`, `lastName` and `email` are required, and `email` must be unique. `dateOfBirth` is optional (`YYYY-MM-DD`).

### Examples

```sh
# list
curl http://localhost:8080/api/persons

# create
curl -X POST http://localhost:8080/api/persons \
  -H "Content-Type: application/json" \
  -d '{"firstName":"Grace","lastName":"Hopper","email":"grace@example.com","dateOfBirth":"1906-12-09"}'

# update
curl -X PUT http://localhost:8080/api/persons/1 \
  -H "Content-Type: application/json" \
  -d '{"firstName":"John","lastName":"Doe","email":"jdoe@example.com","dateOfBirth":"1990-05-14"}'

# delete
curl -X DELETE http://localhost:8080/api/persons/1
```

## Database

- An in-memory H2 database (`jdbc:h2:mem:nomanualcode`, user `sa`, empty password) is used. **All data is lost on restart.**
- On startup, [schema.sql](src/main/resources/schema.sql) recreates the `person` table and [insert.sql](src/main/resources/insert.sql) seeds 8 sample rows. Hibernate DDL generation is turned off (`ddl-auto: none`), so schema changes go in `schema.sql`.
- The H2 web console is at <http://localhost:8080/h2-console>. Use the JDBC URL above to connect.
- SQL statements are logged (`show-sql: true`).

Configuration lives in [application.yaml](src/main/resources/application.yaml).

## Notes

- `TestcontainersConfiguration` has no containers yet. If you move to a real database such as PostgreSQL, declare a container bean there. You can then run `TestNomanualcodeApplication` to start the app against it locally (requires Docker).
- There is no input validation yet.
- CORS isn't configured, and it doesn't need to be. The frontend proxies `/api/persons` through its own origin. See [../nomanualcodeui/README.md](../nomanualcodeui/README.md#talking-to-the-backend).
